# Citation

Metafor.jl is experimental and has not been released as a registered Julia package. If you use this software, cite the exact source version or commit you used and include an access date.

```text
Nakagawa, S., Yang, Y., & Viechtbauer, W. Metafor.jl: selected native Julia methods for meta-analysis. Experimental software. https://github.com/itchyshin/Metafor.jl
```

The project-intended team is Shinichi Nakagawa, Yefeng Yang, and Wolfgang Viechtbauer. This citation reflects the repository's stated intended maintainers; it does not imply that anyone has accepted a role. Wolfgang Viechtbauer is the author of the separate upstream R package [`metafor`](https://www.metafor-project.org/).

The Julia port is licensed under [GPL-2.0-or-later](https://github.com/itchyshin/Metafor.jl/blob/main/LICENSE). See [the upstream project's citation information](https://wviechtb.github.io/metafor/) when citing R `metafor` or its methods.
