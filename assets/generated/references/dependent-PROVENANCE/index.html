Dependent-effects fixture provenance

  • Fixture version: dependent-v1 (synthetic; generated 2026-11-24).
  • R: 4.6.0.
  • metafor: CRAN 5.2-1; source archive SHA-256 25c421cf52279294b11ab3166adfeb327dd22034a03a46487f081a19a163339b.
  • metadat: 1.6-0; Matrix: 1.7-5; numDeriv: 2016.8-1.1; nlme: 3.1-169; mathjaxr: 2.0-0; pbapply: 1.7-4; digest: 0.6.39.
  • metafor source: CRAN package page and CRAN source archive.
  • Reference function: rma.mv() with method="REML", test="z", and default optimizer nlminb; the GLS case fixes the random intercept variance at zero.
  • Data terms: all rows, covariance matrices, moderator values, and outcomes in this fixture were generated by generate.R from fixed seeds. No published dataset, upstream tutorial wording, or figure was copied or adapted. The Berkey-style case is a synthetic two-outcome example, not dat.berkey1998.
  • License/provenance boundary: generate.R is original fixture-generation code. The metafor archive is not included. The R package remains distributed under its CRAN-listed GPL terms; this repository does not contain copied package code.

Regenerate from the repository root after installing the pinned source archive and listed dependencies into an isolated R library:

R_LIBS=/path/to/pinned-R-library Rscript reference/dependent/v1/generate.R

REFERENCE-VERSIONS.txt records the runtime versions and generator seeds. Input and output file checksums are recorded in SHA256SUMS.
